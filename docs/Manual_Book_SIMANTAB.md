## 1. Pendahuluan
**SIMANTAB** adalah Sistem Manajemen Keanggotaan, Kehadiran, dan Keuangan yang dirancang untuk memudahkan pengurus dalam mengelola data secara terpusat, real-time, dan efisien. Sistem ini memiliki dua jenis hak akses utama: **Admin (Pengurus)** dan **Member (Anggota)**.

## 2. Akses Sistem (Login)
Untuk masuk ke dalam sistem, pengguna harus melakukan otentikasi melalui halaman Login.

### 2.1 Login Admin
1. Buka halaman utama aplikasi SIMANTAB.
2. Masukkan kredensial (Email/Username dan Password) khusus Administrator.
3. Klik tombol **Login**.

### 2.2 Login Anggota (Member)
1. Buka halaman utama aplikasi SIMANTAB.
2. Masukkan ID Anggota atau Username yang telah didaftarkan oleh pengurus.
3. Masukkan Password. *(Catatan: Password default untuk anggota baru biasanya adalah `123` atau sesuai kebijakan pengurus).*
4. Klik tombol **Login**.

---

## 3. Dashboard Utama
Setelah berhasil login sebagai Admin, Anda akan diarahkan ke halaman **Dashboard**. Halaman ini memberikan ringkasan (statistik) metrik utama, meliputi:
- **Total Anggota:** Menampilkan jumlah keseluruhan anggota aktif yang terdaftar.
- **Persentase Kehadiran:** Menampilkan rata-rata persentase kehadiran anggota dalam bulan berjalan.
- **Performa/Kegiatan (Ikon Drum):** Menampilkan jumlah kegiatan atau *performance* yang telah/akan dilaksanakan.

---

## 4. Manajemen Anggota
Modul ini digunakan untuk mengelola data master anggota.

### 4.1 Menambah Anggota Baru
1. Navigasi ke menu **Data Anggota**.
2. Klik tombol **Tambah Anggota** (akan memunculkan *Modal* pendaftaran).
3. Isi formulir pendaftaran (Nama, Divisi, Kontak, dll).
4. Klik **Simpan**.

### 4.2 Fitur Pengelolaan Anggota
- **Pengelompokan Divisi:** Daftar anggota dapat dilihat dan disortir berdasarkan divisi masing-masing untuk memudahkan pencarian.
- **Ekspor PDF:** Anda dapat mencetak atau mengunduh daftar anggota ke dalam format PDF dengan mengklik tombol **Export PDF**.

---

## 5. Manajemen Kehadiran (Absensi)
Modul ini berfungsi untuk mencatat dan melacak kehadiran anggota pada setiap kegiatan atau jadwal latihan.

### 5.1 Input Kehadiran
1. Masuk ke menu **Kehadiran**.
2. Pilih jadwal atau tanggal kegiatan.
3. Daftar anggota akan ditampilkan (mendukung *sorting/reordering* berdasarkan divisi).
4. Tandai status kehadiran (Hadir, Izin, Sakit, Alpa) untuk setiap anggota.
5. Klik **Simpan Absensi**.

### 5.2 Riwayat Kehadiran (Attendance History)
1. Buka tab atau menu **Riwayat Kehadiran**.
2. Gunakan **Filter Bulan dan Tahun** di bagian atas untuk melihat data spesifik.
3. Anda dapat melihat rekapitulasi kehadiran dan melakukan **Edit** jika terdapat kesalahan input pada hari sebelumnya.

---

## 6. Manajemen Keuangan
Modul keuangan SIMANTAB dibagi menjadi beberapa kategori untuk pembukuan yang terstruktur.

### 6.1 Kategori Keuangan
- **Keuangan Pengurus:** Mencatat kas operasional pengurus.
- **Keuangan Media:** Mencatat dana khusus untuk kebutuhan media/dokumentasi.

### 6.2 Input Transaksi (Uang Masuk / Keluar)
1. Masuk ke menu **Keuangan** (pilih Pengurus atau Media).
2. Klik tombol **Tambah Transaksi** (sebelumnya bernama *Input Manual*).
3. Pilih jenis transaksi: **Uang Masuk (Pemasukan)** atau **Uang Keluar (Pengeluaran)**.
4. Masukkan nominal, tanggal, dan keterangan transaksi.
5. Klik **Simpan**. Saldo (Total Funds) akan otomatis terbarui.

### 6.3 Setoran dan Penarikan
- Sistem menyediakan halaman riwayat komprehensif berwujud tabel untuk memantau detail riwayat **Setoran** dan **Penarikan** anggota secara transparan.

---

## 7. Manajemen Jadwal Kegiatan
Modul ini digunakan untuk merencanakan dan melihat agenda operasional / latihan.
1. Navigasi ke menu **Jadwal**.
2. Tampilan menggunakan format **Tabel Agenda** yang bersih dan profesional.
3. Admin dapat menambahkan jadwal kegiatan baru (Tanggal, Waktu, Lokasi, Nama Kegiatan).

---

## 8. Pengaturan Sistem
Menu khusus Admin untuk melakukan penyesuaian teknis pada aplikasi SIMANTAB.
1. Navigasi ke menu **Pengaturan (Settings)**.
2. Di sini admin dapat mengelola parameter aplikasi, melakukan *reset password* pengguna, atau memantau sinkronisasi *real-time* sistem.

---

## 9. Akses Portal Anggota
Saat Anggota login dengan akun mereka masing-masing, mereka akan melihat antarmuka yang disederhanakan, meliputi:
- **Profil Saya:** Melihat informasi detail akun dan divisi.
- **Informasi Jadwal:** Melihat jadwal kegiatan atau *performance* yang akan datang.
- **Riwayat Kehadiran:** Memantau rekap absensi diri sendiri.
- **Informasi Keuangan Pribadi (Jika diaktifkan):** Melihat riwayat setoran atau tagihan pribadi.
